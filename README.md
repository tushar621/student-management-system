# Student Management System

A menu-driven console application written in Java for managing student records. It stores students in a HashMap, uses a custom exception for missing records, and handles invalid input without crashing.

## Features
- Add, view, search, update marks and delete students
- Custom exception (StudentNotFoundException) for missing students
- Input validation so wrong input doesn't crash the program

## Concepts used
OOP (classes, encapsulation), HashMap, exception handling, switch, loops, Scanner

## How to run
1. Clone the repository
2. Open it in IntelliJ IDEA
3. Run Student_Management_System.java
